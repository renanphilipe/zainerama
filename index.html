📖 Como configurar — Passo a Passo

  1. Acesse supabase.com, crie uma conta gratuita e clique em "New Project". Escolha um nome (ex: zainerama) e uma senha forte.
  2. No painel do projeto, vá em Settings → API. Copie a Project URL e a chave anon / public e cole nos campos acima.
  3. Agora crie a tabela. Vá em SQL Editor e execute o SQL abaixo — ele cria tudo automaticamente:
-- Cole e execute no SQL Editor do Supabase CREATE TABLE IF NOT EXISTS zainerama_config ( key TEXT PRIMARY KEY, value TEXT NOT NULL, updated_at TIMESTAMPTZ DEFAULT now() ); -- Habilitar Row Level Security (RLS) ALTER TABLE zainerama_config ENABLE ROW LEVEL SECURITY; -- Política: leitura pública (para carregar o site) CREATE POLICY "public_read" ON zainerama_config FOR SELECT USING (true); -- Política: escrita apenas com anon key (admin autenticado) CREATE POLICY "anon_write" ON zainerama_config FOR ALL USING (true) WITH CHECK (true);
  1. Cole a URL e a Anon Key nos campos acima e clique em SALVAR E CONECTAR. O badge no canto inferior esquerdo vai ficar verde ✅
  2. Para imagens no portfólio com Supabase, use o Supabase Storage: vá em Storage → New Bucket, crie um bucket público chamado portfolio, faça upload das fotos e copie a URL pública de cada uma.
  3. Pronto! Todos os dados do site (links, grupos, senhas) serão salvos no Supabase e sincronizados em qualquer dispositivo. O localStorage continua como backup automático.

⚠️ Nota sobre imagens: O Supabase armazena apenas texto/JSON. Para imagens, use o Supabase Storage ou serviços externos (Cloudinary, imgbb, etc.) e salve apenas as URLs no banco. O upload direto de arquivo funciona apenas com localStorage.
